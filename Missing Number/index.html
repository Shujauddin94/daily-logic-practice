🧩 Find the Missing Number

The Problem (Super Simple)

You have numbers from 1 to n.

👉 One number is missing.

Example:

[1, 2, 4, 5]

Numbers should be:

1, 2, 3, 4, 5

👉 3 is missing

🧠 Think of It Like This (Real-Life Example)

Imagine you have 5 candies numbered:

1  2  3  4  5

But your friend gives you only:

1  2  4  5

You ask:

"Which candy number is missing?"

🔢 Step 1: Add ALL numbers from 1 to n

If n = 5:

1 + 2 + 3 + 4 + 5 = 15

So 15 is the total if nothing was missing.

🔢 Step 2: Add the numbers you ACTUALLY have

[1, 2, 4, 5]
1 + 2 + 4 + 5 = 12

➖ Step 3: Subtract

15 - 12 = 3

🎉 3 is the missing number

🧑‍💻 JavaScript Code

function findMissingNumber(arr, n) {
    let expectedSum = n * (n + 1) / 2;
    let actualSum = 0;

    for (let i = 0; i < arr.length; i++) {
        actualSum = actualSum + arr[i];
    }

    return expectedSum - actualSum;
}

🧪 Example Run

let numbers = [1, 2, 4, 5];
let n = 5;

console.log(findMissingNumber(numbers, n)); // 3
